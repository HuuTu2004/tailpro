TailPro 0.1.0 Preview brings saved SSH connections and an Open logs picker with Found sources, Browse folders and Enter path. Choose multiple sources, remember scan locations and optionally restore readers after reconnecting. The viewer has Columns, Time and Status controls, plus search, details and redacted exports.

Downloads: Windows x64 NSIS installer; Linux x64 deb and AppImage; macOS Apple Silicon and Intel DMG. Matching MCP adapter ZIPs and SHA256SUMS.txt are included.

These preview packages do not have paid Windows/Apple signing certificates; macOS uses ad-hoc signing without notarization. Windows readers require key/Windows OpenSSH-agent authentication; password/keyboard-interactive sessions require a Linux or macOS client. Remote hosts require a POSIX shell and Python 3. Remote Windows readers and compressed archive reading are not supported.

Native package builds do not certify all runtime scenarios. See README and docs/process/current-status.md for prerequisites, live-host evidence and remaining runtime gates.
